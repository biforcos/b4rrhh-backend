# Domain Documentation

This folder contains documentation about the B4RRHH domain model.

Key documents:

- `rule-system-and-regulated-entities.md` — origin document of the catalog metamodel
  (rule systems, rule entity types and rule entities). Still describes what exists.
- `data-dictionary-concept.md` — a direction that is still open.
- `employee-presence-field-reference-mapping.md` — how employee presence fields map to
  their references.
- `employee/` — per-vertical domain notes for the employee bounded context.

The architectural decisions themselves live in `../architecture/adr/` (see `ADR_BUNDLE.md`).
Historical documents that described earlier versions of the model were removed; they are in
the git history if ever needed.
